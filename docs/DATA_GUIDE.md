# 数据资料位置与精简说明

核对日期：2026-10-22。[当前状态](../README.md) · [完整筛查历史](../search_results.md) · [统一下载入口](../data/packages/README.md)

## 1 日常使用只需三个入口

1. 看当前数量与用法：仓库首页。
2. 下载与分析：v3完整数据包。
3. 回查为什么纳入或排除：v3全量审计、51篇复核台账和本仓库筛查历史。

历史包不必全部下载，也不要将v1、v2、v3一起导入分析工具。
