# AI4S 文献检索策略与结果

本项目公开AI for Science文献检索的设计、完整检索式、词项来源和结果记录，为研究主题演化与科研介入方式变化提供可核查的起点。

## 研究背景与设计

本研究将AI4S界定为AI在数学、自然科学或工程科学中承担可识别的科研任务，例如规律发现、性质预测、结构与分子设计、实验规划或机理约束求解。采用三条互补路径，检索结果再经内容核验。

| 逻辑块 | 识别路径 | 字段 |
| --- | --- | --- |
| 1 | 显式AI4S及自主实验室表述 | TS |
| 2 | AI方法 AND 科研任务 AND 科学领域 | (TI OR AK) AND AB AND TS |
| 3 | Scientific Machine Learning AND 方程或物理约束 | TS AND AB |

三个逻辑块以OR连接，整体限定`PY=(2010-2026)`、`LA=(English)`、`DT=(Article)`。领域条件仅作用于第二块。TS含Keywords Plus；同篇共现不自动证明AI实际承担科研任务。

检索词按官方政策与学科资助范围、英文规范化、代表性文献与领域用语补充构建。来源分为A（官方直接点名概念）、B（语义操作化）和C（文献或领域惯用语补充），详见检索词文档。
