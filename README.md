## 这些数据是怎样确定的

11,637条原始导出 → 前期筛除及撤稿移除后10,315条 → 领域筛除后10,189条 → v1核心8,247篇 → 复核1,412篇后v2核心9,446篇 → 补证51篇后v3核心9,470篇。

其中51篇补证有31篇形成归类结论，20篇仍待证据。“全部有筛查记录”与“全部完成全文终审”是不同状态；原8,247篇沿用模型辅助筛选，后续复核层级见逐篇台账。

## 研究范围与接续工作

本项目研究AI实质参与数学、自然科学及工程科学问题求解的主题演化与科研介入方式，采用文献计量与重点文献内容分析相结合的方法。观察范围为2010—2026年，2010—2025年用于完整年度比较，2026年单列。上述数量均为WoS数据，CNKI另行整理与分析。

检索采用“显式AI4S表述”“AI方法×科研任务×科学领域”“Scientific Machine Learning×方程或物理约束”三条路径；全局限制为 `PY=(2010-2026) AND LA=(English) AND DT=(Article)`。检索式锁定后，v1—v3更新的是筛查结果。

接续工作：处理20篇补证记录，以9,470篇重算描述性统计和图谱，完成关键词、机构等规范化，并统一论文第二章及结果章节口径。旧11,608篇统计保留原分母。
